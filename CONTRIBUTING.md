# Contribution guidelines

This document describes how to contribute to this patch bundle.

## 📖 Resources to help you get started

* [Issues](https://github.com/dh6k/morphe-patches/issues) track bugs and feature requests.

## 🙏 Submitting a feature request

Features can be requested by opening an issue using the
[Feature request issue template](https://github.com/dh6k/morphe-patches/issues/new?template=feature_request.yml).

## 🐞 Submitting a bug report

If you encounter a bug, open an issue using the
[bug report issue template](https://github.com/dh6k/morphe-patches/issues/new?template=bug_report.yml).

## 📝 How to contribute

1. Open an issue first when proposed behavior or scope needs discussion.
2. Fork the repository and create a branch from `dev`.
3. Make and test the change.
4. Submit a pull request to `dev`. Reference any issue it closes.
5. Address review feedback. Approved changes are merged into `dev` for the next development release.
